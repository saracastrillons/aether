The platform

From spreadsheet to decision,
with the math in plain sight.

Forecast Lab

Four models — OLS with Fourier seasonality, Holt smoothing, seasonal naive and naive — compete in rolling-origin cross-validation. The winner is chosen by backtested MAPE, not by vibes.

Explainable AI analyst

Ask in plain language. Every answer ships with the SQL, formulas and sources used — optionally narrated by Claude, never with invented numbers.

Robust anomaly detection

Median/MAD z-scores on growth flag outliers and attribute them to the region that moved the most.

Churn risk model

Logistic regression with a 30% holdout: ROC/AUC, confusion matrix, per-customer drivers and next-best actions.

Scenario simulator

Move price, marketing and churn; see the forecast and a revenue bridge recompute live.

Built like a real SaaS

Multi-tenant organizations, admin / analyst / viewer roles enforced by the API, expiring invite links, audit log, login throttling, security headers and an automated test suite.

How it works

A transparent pipeline,
end to end.

  1. 01

    Ingest

    Upload a CSV or start from demo data. Each organization's data is isolated.

  2. 02

    Validate

    Schema checks, deduplication and a data-quality score before anything is modeled.

  3. 03

    Model

    Backtested forecasts, anomaly scoring and a churn classifier, recomputed on every change.

  4. 04

    Explain

    Insights, an AI analyst with its reasoning visible, and a one-click executive report.
